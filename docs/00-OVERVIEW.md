# Вольница — обзор проекта

**Продукт:** сайт проката «Вольница» + CRM на Payload  
**Заказчик:** ООО «Цементоптторг-Риэлт»  
**Этап:** 70 000 ₽ / 35 ч (US-01…US-06)  
**Дизайн:** прототипы 1:1 · **Цены/маршруты:** бизнес-план 02.09.2026

## Стек

| Слой | Решение |
|------|---------|
| Сайт | Next.js (App Router) на **Vercel** |
| CRM + CMS | **Payload** (opensource), форк/кастом под бизнес |
| БД | PostgreSQL (Neon / Vercel Postgres) |
| Домен | **.ru** → DNS Vercel, SSL |
| Уведомления | Telegram **или** email (один канал) |
| Заявки | все формы → CRM: Заявки + Клиенты + лог уведомлений |

## Зафиксировано

- Хостинг: Vercel · домен: .ru  
- Маршруты: Зелёное озеро → Памятник → Родник → Экспедиция (+ ночной отдельно)  
- Прогресс: новая учётка → только трасса 1; после «пройден» админом → следующая  
- Все заявки падают в Payload CRM (не во внешнюю CRM)
