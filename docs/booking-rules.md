# Правила бронирования Вольница

Источник: голосовое ТЗ заказчика + бизнес-план 02.09.2026 + ТЗ US-04/US-06.  
Статус: рабочая договорённость для разработки (спринты 2–4).

---

## 1. Режим работы

- Ежедневно **10:00–22:00** (МСК).
- Дневные записи — в рабочие окошки стартов внутри этого окна.
- Ночные программы — **отдельный продукт**, время согласуется вручную.

---

## 2. Дневные тарифы / маршруты

Цена за клиентский квадроцикл. В группе — машина инструктора.

| Маршрут | Текст длительности | `durationMinutes` (для слотов) | Цена |
|---------|-------------------|-------------------------------|------|
| Зелёное озеро | 45–60 мин | **60** | 5 500 ₽ |
| Памятник | 1–1,5 ч | **90** | 7 500 ₽ |
| Родник | 1–2 ч | **120** | 10 000 ₽ |
| Экспедиция | уточняется → ориентир 3 ч | **180** | 12 000 ₽ |

Голос заказчика: длительности ориентировочно **1 / 1.5 / 2 / 3 ч** в зависимости от тарифа — таблица выше мапит маршруты на минуты для расчёта занятости.

**Стартовые окошки (день):** 10:00, 12:00, 14:00, 16:00, 18:00, 20:00.  
**Занятость:** интервал `[start, start + durationMinutes)` — пересечения блокируют слот.  
**Capacity:** до **3** активных заявок на один стартовый слот (при отсутствии пересечения по интервалу учитывается как сейчас; при интервальной модели — capacity на пересекающиеся брони).

Прогресс маршрутов (ЛК): строго 1 → 2 → 3 → 4 после отметки админом «пройден».  
По ТЗ: **гость может оставить обычную заявку без прогресса**; дневная запись с прогрессом — через вход в ЛК.

---

## 3. Ночной тариф / квест

- Страница `/nochnoj-kvest`, ориентир **15 000 ₽ за двоих**.
- Сценарий: выбрал ночной → оставил заявку (имя, телефон, гости, комментарий) → менеджер пишет в WhatsApp/Telegram → дату/время согласуют в переписке.
- **Нет** обязательного календарного слота.
- **Нет** обязательной авторизации перед ночной заявкой.
- В CRM: `bookingKind = night`, слот/дата опциональны.

---

## 4. Сезоны и паузы

Цикл:

```
квадроциклы → пауза (осадки) → снегоходы → пауза (снег сходит) → квадроциклы
```

- В паузу **сайт не выключать** — принимать брони на будущие даты/сезон.
- Локальные закрытые дни/периоды — админ **Календарь → Остановка** (`closedRanges`).
- Текущий сезон в CMS (`atv` / `snow` / `pause`); услуги с `season` + `activeForBooking`.
- Сапы / лошади — выключенные заготовки (`published=false` / без онлайн-брони), не в текущем релизе.

---

## 5. Что в заявке (минимум)

| Поле | День | Ночь |
|------|------|------|
| Имя, телефон | да | да |
| Дата + стартовый слот | да | нет (опционально позже) |
| Маршрут / тариф | да | «Ночной квест» |
| Гости, комментарий | да | да |
| `durationMinutes` | да | нет |
| `bookingKind` | `day` | `night` |

---

## 6. Критерии готовности по спринтам

1. Этот документ согласован как база.
2. Ночная заявка без слота попадает в CRM.
3. Дневная бронь учитывает длительность тарифа (пересечения).
4. Сезон переключается в CMS; пауза не роняет сайт; стопы дней работают.
