# Брендбук сайта «Вольница»

> Территория свободы · Premium outdoor · Казань / КФХ Тверетиновка · Усадьба «Берегиня»

## 1. Позиционирование

| Параметр | Значение |
|----------|----------|
| Суть | Премиальный прокат квадроциклов (летом) и снегоходов (зимой) |
| Тон | Свобода, адреналин, безопасность, гостеприимство базы |
| Не тон | Дешёвый прокат, детский парк, «просто каталки» |
| Аудитория | Компании друзей, семьи, корпоративы, туристы |

**Слоган:** Территория свободы  
**Ключевой оффер hero:** Премиальный отдых на природе · Прокат квадроциклов

## 2. Визуальный язык (по прототипам)

### 2.1. Настроение
- Тёмная премиальная тема (почти чёрный фон)
- Кинематографичные фото: грязь, лес, закат, фары, костёр
- Золотой/медный акцент — «люкс + природа», не неон
- Тонкие line-иконки в акценте
- Прямоугольные кнопки (без «пилюль»), тонкая золотая обводка у ghost-CTA

### 2.2. Цвета (CSS-токены)

```css
:root {
  /* Surfaces — near-black + лёгкий тёмно-зелёный undertone (БП §9) */
  --bg-void: #040605;
  --bg-base: #0A0F0C;
  --bg-elevated: #121A16;
  --bg-card: #161E1A;
  --bg-overlay: rgba(0, 0, 0, 0.55);

  /* Brand accent — тёплый золото/медь (не фиолетовый, не неон) */
  --accent: #C9954A;
  --accent-hover: #D9A85C;
  --accent-muted: rgba(201, 149, 74, 0.15);
  --accent-border: rgba(201, 149, 74, 0.55);

  /* Text */
  --text-primary: #F5F5F5;
  --text-secondary: #A8A29A;
  --text-muted: #6B6560;
  --text-on-accent: #0A0A0A;

  /* Difficulty / badges */
  --diff-easy: #3D8B5A;      /* Зелёное озеро / Лёгкий */
  --diff-medium: #C9954A;    /* Лесные тропы / Средний */
  --diff-hard: #B84A3A;      /* Легенда / Сложный */
  --badge-standard: #3D8B5A;
  --badge-premium: #C9954A;
  --badge-legend: #B84A3A;

  /* UI */
  --border-subtle: rgba(255, 255, 255, 0.08);
  --border-accent: 1px solid var(--accent-border);
  --focus-ring: 0 0 0 2px var(--bg-base), 0 0 0 4px var(--accent);
}
```

**Правило:** акцент один — золото/медь. Не добавлять фиолетовые градиенты, glow-неоновые эффекты, «AI purple».

### 2.3. Типографика

| Роль | Рекомендация | Использование |
|------|--------------|---------------|
| Display / H1 | **Cinzel** или **Playfair Display** (serif) *или* жирный caps sans (**Montserrat** / **Unbounded**) — как в конкретном экране прототипа | Hero, названия разделов |
| UI / Body | **Manrope** или **Montserrat** | Навигация, карточки, формы |
| Meta / caps | Same sans, tracking 0.08–0.14em, uppercase | Хлебные крошки, лейблы, бейджи |

**Иерархия hero (типичная):**
1. Малый лейбл (серый/золото): «ПРЕМИАЛЬНЫЙ ОТДЫХ НА ПРИРОДЕ»
2. Крупный H1 (белый caps): «ПРОКАТ КВАДРОЦИКЛОВ»
3. Подзаголовок золотом: «ТЕРРИТОРИЯ СВОБОДЫ»

**Подключение (Google Fonts):**
```html
<link href="https://fonts.googleapis.com/css2?family=Cinzel:wght@500;700&family=Manrope:wght@400;500;600;700&display=swap" rel="stylesheet">
```

```css
--font-display: "Cinzel", "Times New Roman", serif;
--font-body: "Manrope", system-ui, sans-serif;
```

### 2.4. Логотип
- Знак: стилизованный крест / «X» / геометрический эмблем (золото)
- Слово: **ВОЛЬНИЦА**
- Подпись: территория свободы (мелкий caps)
- На тёмном фоне — светлый/золотой вариант; инверсия не нужна (сайт всегда dark)

### 2.5. Иконография
- Стиль: thin line, 1.5–2px stroke, цвет `--accent`
- Сетка: 24×24 / 32×32
- Темы: щит, шлем, квадроцикл, карта, костёр, фары, дом/усадьба, календарь, топливо, горы

### 2.6. Фотостиль
- Полноэкранные edge-to-edge hero (без inset-карточек в первом экране)
- Затемнение оверлеем `--bg-overlay` для читаемости текста
- Тёплый golden hour / ночные фары / грязь / лес / усадьба у воды
- Контент фото готовит Заказчик (вне scope копирайт/съёмка)

### 2.7. Компоненты UI

| Компонент | Спека |
|-----------|--------|
| Primary button | solid `--accent`, текст `--text-on-accent`, radius 0–4px |
| Ghost button | прозрачный + border accent, текст accent/white |
| Card | `--bg-card`, тонкая граница, без тяжёлых теней |
| Header | прозрачный → solid на скролле; sticky |
| Mobile sticky CTA | полный width, золотой бар «ЗАБРОНИРОВАТЬ СЕЙЧАС» |
| Accordion FAQ | иконка слева, +/− справа, разделители accent |
| Difficulty badge | цветной пилл/плашка по `--diff-*` |
| Tariff badge | СТАНДАРТ / ПРЕМИУМ / ЛЕГЕНДА |

### 2.8. Motion (минимум 2–3 осознанных)
1. Header: fade/blur фона при scroll
2. Hero: лёгкий fade-up заголовка + кнопок (300–500ms)
3. Карточки маршрутов/техники: hover border → accent, image slight scale
4. Mobile: carousel swipe маршрутов/тарифов
5. FAQ: плавное раскрытие accordion

Не: бесконечный parallax, glow-particles, emoji-анимации.

## 3. Голос бренда (копирайт)

**Да:** «территория свободы», «авторские маршруты», «премиальный отдых», «безопасность прежде всего», конкретика (время, км, уровень).  
**Нет:** канцелярит, кликбейт «лучший в мире», перегруз статистики в hero.

**CTA словарь:**
- Забронировать / Забронировать сейчас
- Выбрать маршрут
- Подробнее
- Подобрать технику / тариф
- Смотреть видео

## 5. Do / Don't

| Do | Don't |
|----|-------|
| Тёмный фон + золотой акцент | Светлая «корпоративная» тема |
| Full-bleed hero | Hero в карточке с скруглением |
| Один главный CTA на экран | Статистика + промо + адрес в первом viewport сверх прототипа |
| Карточки только для выбора (маршрут, техника, тариф) | Декоративные card-обёртки вокруг всего |
| Следовать прототипу 1:1 | Новые экраны без согласования |
