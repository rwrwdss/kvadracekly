# Страницы: состав, секции, реализация 1:1

Легенда реализации:
- **Макет** — есть JPG-прототип
- **Паттерн** — собираем из существующих блоков брендбука
- **Минимум** — функционал US без отдельного дизайна

---

## Общие компоненты (все страницы)

| Компонент | Поведение |
|-----------|-----------|
| `SiteHeader` | Logo + nav + ghost «Забронировать»; mobile hamburger; sticky; active underline accent |
| `SiteFooter` / bottom CTA | По макету страницы (часто золотая кнопка брони) |
| `StickyBookBar` | Только mobile: «ЗАБРОНИРОВАТЬ СЕЙЧАС · Быстрое бронирование в 1 клик» |
| `BookingModal` | Форма заявки; открывается со всех CTA |
| `Breadcrumbs` | `Главная > …` на внутренних |
| `IconFeatureRow` | 4 колонки line-icon + подпись |
| `PageHero` | Full-bleed фото + H1 + золотой подзаголовок |

**Берём UI:** 04 (4 карточки + нижний CTA)  
**Данные:** бизнес-план 02.09.2026 (не названия из старых макетов)

### Секции
1. Hero: «НАШИ МАРШРУТЫ» / «Авторские тропы для любого уровня» + 4 meta-иконки + **«Смотреть на карте»** (единая карта всех треков)
2. Сетка/карусель **4 карточек**
3. Features: Уникальные локации · Фотостопы · Безопасность · Индивидуальный подход
4. CTA: «Не нашли маршрут? Соберём индивидуальный» → контакт/бронь

### Карточка маршрута
- Бейдж сложности (цвет) + **цена**
- Мини-схема трека **или** акцент на общую карту (БП: не отдельный баннер-карта на каждый)
- Название, описание
- Meta: длительность · км · аудитория
- Ghost «Подробнее» · Solid «Выбрать маршрут»

### Seed (бизнес-план)
| Маршрут | Уровень | Время | Км | Цена | Прогресс |

| Зелёное озеро | Лёгкий | 45–60 мин | 9–11 | 5 500 ₽ | 1 |
| Памятник | Средний | 1–1,5 ч | 13–15 | 7 500 ₽ | 2 |
| Родник | Средний+ | 1–2 ч | 15–22 | 10 000 ₽ | 3 |
| Экспедиция | Сложный | уточн. | уточн. | 12 000 ₽ | 4 |
