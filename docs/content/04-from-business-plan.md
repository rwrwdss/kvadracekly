**На сайте `/marshruty`:** 4 карточки = Зелёное озеро · Памятник · Родник · Экспедиция.  
**Ночной** — не в общем ряду как 5-я дневная карточка, а лендинг `/nochnoj-kvest` + пункт меню.

### Карта (важно из БП)
Одна **единая карта** всех маршрутов (не отдельный баннер на каждый): дороги, грязевые участки (коричневые), точки остановок. Маршруты **конечные с возвратом на базу**.

**Точки на карте:** старт/финиш КФХ · Зелёное озеро · высохший карьер · пасека · смотровая · дом охотника · тёмный лес · памятник · нора лисы · деревянный мост («Мономост») · родник. Кресты = остановки.

### Черновики описаний карточек

**Зелёное озеро** — лёгкий вводный маршрут к озеру; комфортный темп; для новичков, пар, семей.  
**Памятник** — средний; больше километраж и рельеф; точки интереса по карте.  
**Родник** — длиннее и насыщеннее (до 22 км); для уверенных.  
**Экспедиция** — флагман дневной программы; время/км уточняются; для уровня «Вольный».

## 2. Рейтинговая система и прогресс маршрутов (ЛК / US-06)

**Рабочая логика сайта (как хочет клиент):** строго по порядку трасс.

```
1. Зелёное озеро → 2. Памятник → 3. Родник → 4. Экспедиция
```

Новый клиент бронирует только №1. После отметки «пройден» админом открывается №2, затем №3, затем №4.  
Полное описание: [05-ROUTE-PROGRESS.md](../05-ROUTE-PROGRESS.md).

Уровни из БП (Новичок / Следопыт / Вольный) — **маркетинговые названия** поверх той же цепочки:

| Уровень БП | Условие | Что открывает |
|------------|---------|---------------|
| 1. Новичок | Инструктаж + первый маршрут | Зелёное озеро (и повтор) |
| 2. Следопыт | Пройдены базовые | Памятник, затем Родник |
| 3. Вольный | Навыки и дисциплина | Экспедиция / спецпрограммы |
| 4. Самостоятельный допуск | Инструктор + документы | Не продаём на сайте до юр. готовности |
