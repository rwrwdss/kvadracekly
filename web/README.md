# Вольница — сайт

```bash
cd web
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Страницы

- `/` — главная
- `/marshruty` — маршруты (БП)
- `/tehnika` — техника
- `/tarify` — тарифы
- `/nochnoj-kvest` — ночной квест
- `/usadba` — усадьба
- `/galereya` — галерея
- `/faq` — FAQ
- `/lk` — личный кабинет (демо прогресса 1→2→3→4)

Заявки: `POST /api/leads` (пока лог в консоль; далее Payload CRM).

Документация архитектуры: `../docs/`.
